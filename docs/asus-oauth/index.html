專業摘要

具備 Keycloak 服務間 OAuth 串接、client 設定及 API 驗證授權經驗。曾獨立規劃並上線跨 Session／JWT 的憑證撤銷與閒置逾時功能，處理 token refresh、多分頁競爭及跨系統一致性。另具 HMAC 驗證、可恢復工作流、PHP／Java API 開發與 Kubernetes 部署經驗。
